# CMX Harness

CMX Harness is a product specification for a single-team DevOps delivery platform.

The platform owns the delivery loop for requirements, tasks, tests, releases, acceptance, and metrics, while GitHub owns source control, pull requests, code review, GitHub Actions execution, and deployment signals.
